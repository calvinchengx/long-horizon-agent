The model thinks in short bursts; the **system** runs for weeks. LHA treats long-horizon autonomy
as an engineering problem, not a model capability.

<CardGrid>
  <Card title="Truth outside the model" icon="document">
    A git repo plus a structured checklist, progress log and decision log (the `.lha/` mission
    anchor) is re-read every cycle, so a restart rebuilds situational awareness in seconds.
  </Card>
  <Card title="Durable execution" icon="rocket">
    Missions run as Temporal workflows. Each agent cycle is a journaled activity: a crashed worker
    resumes from the last completed cycle, and waiting on an outage is a durable timer.
  </Card>
  <Card title="Deterministic verification" icon="approve-check">
    An item is done only when real tests, lint and type checks pass in the sandbox, never on the
    model's say-so.
  </Card>
  <Card title="Guardrails" icon="warning">
    Sandboxed execution, irreversible commands refused outright, default-deny
    egress and a budget governor that stops spend before it happens.
  </Card>
</CardGrid>
